# 복제 모드 개발판

v1.4.1 복제 모드의 개발·검증 기록입니다. 초기 미검증 항목은 아래 추가 검증과 docs/VALIDATION.md의 최신 결과를 함께 확인하세요.

## 변경

- 선택한 물리 모니터의 위치와 해상도를 유지합니다.
- 첫 영역은 기존 물리 모니터를 캡처하고 축소 표시합니다.
- 나머지 영역만 가상 모니터를 사용합니다. 4분할에는 추가 논리 화면 3개가 필요합니다.
- 기존 창·아이콘을 첫 가상 화면으로 옮기는 동작을 제거했습니다.
- 출력 창을 WDA_EXCLUDEFROMCAPTURE로 제외합니다.
- 원본의 가림에 따른 갱신 중단을 방지하기 위해 출력 창의 불투명도를 99%로 설정했습니다. 원본 비침과 화질은 미검증입니다.
- 입력은 표시 좌표와 원본 좌표를 나눠 관리하는 MirrorPointer로 변경했습니다.
- 종료 시 추가 가상 화면의 일반 창을 물리 화면으로 회수한 뒤 기존 구성을 복원합니다.
- WGC 실패 시 자기 복제에 부적절한 GDI 화면 복사를 자동 선택하지 않습니다.

## 실제 확인

2026-11-13 자기 화면 캡처/출력 시험에서, 출력 창에 가려진 자체 시험 창을 빨강·초록·파랑으로 변경하고 GPU 출력 버퍼에서 각 색상을 확인했습니다. 디스플레이 구성을 변경하지 않은 시험입니다. 완전 불투명 출력에서는 색 갱신이 정지했고 99% 불투명도에서는 세 색 갱신이 통과했습니다.

샌드박스 내부에서는 화면 캡처가 거부되어 실제 Windows 데스크톱에서 검사했습니다. 색상 시험 성공은 네 칸 입력이나 전체 제품의 성공을 뜻하지 않습니다.

전체 세션 검사를 실행했으나 현재 가상 디스플레이 드라이버가 없어 시작 전 실패했습니다. 시작 전에 실패했으므로 시험은 모니터 구성을 바꾸지 않았습니다.

## 남은 필수 검증

- 설치된 드라이버 환경에서 원본 + 가상 3화면 출력과 종료 복원
- 클릭, 드래그, 휠, 한글 입력, 옆 물리 모니터 이동
- 원래 Windows 커서와 복제 커서의 중복/좌표 일치
- 세로 화면, 다른 배율, 병합 비율
- 원본 갱신 유지, 메뉴와 팝업, 일반 앱과 관리자 앱
- 잠금, UAC, 절전, 장치 손실, 비정상 종료
- 전체 프레임/지연 측정

기존 CarryTests와 VirtualTests는 이전 구조를 대상으로 하므로 이 변경을 검증하는 시험으로 사용할 수 없습니다. 공개 배포는 위 검증이 끝난 다음에 진행해야 합니다.


## 2026-11-13 추가 검증

가상 디스플레이 공식 설치 흐름을 실행하고 독립 드라이버 장치 4개 설치를 완료했습니다. 각 분할 세션은 필요한 장치만 활성화합니다.

두 물리 모니터의 grid/cols/rows/top/bottom/full 총 12개 조합에서 자체 창의 실제 클릭·영문 키보드·휠·드래그·영상 갱신·옆 모니터 진입을 확인했고 매번 원래 CCD 구성을 복원했습니다. 이 결과는 자체 시험 창에 대한 결과입니다. 합성 Unicode 패킷은 입력되지 않았으며 이 항목은 통과로 집계하지 않았습니다.

커서의 원본 좌표와 표시 좌표를 분리했고, 시스템 커서를 숨기는 동안 복제 커서를 다른 실제 모니터에도 표시합니다. Raw Input 이동량 수집을 추가해 원본 모니터 경계의 좌표 제한과 표시 경계를 분리했습니다. 이 변경 후 grid의 입력 및 아래쪽 경계 이동을 재검사했습니다. 물리 마우스의 모든 DPI/가속/절대좌표 장치 호환성을 검증한 것은 아닙니다.

앱과 별도 복구 프로세스를 추가했습니다. 분할 중 앱 프로세스를 강제 종료한 뒤 디스플레이·아이콘 복구 기록이 정리되고 원래 CCD 상태가 복원됨을 확인했습니다.

앞선 문서의 '드라이버가 없어 전체 세션 미검증'은 초기 단계의 기록이며 이후 위 검증으로 갱신되었습니다. 세로 하드웨어, 한글 IME, 잠금·UAC·절전 등 별도 시나리오는 여전히 미검증입니다.


## 1.4.1 마우스·테두리 변경

MirrorPointer가 표시 좌표를 실제 물리 모니터 영역으로 제한하고, CursorSurface는 같은 표시 좌표를 직접 사용합니다. 가상 모니터를 Windows 좌표상 한 줄에 배치해도 입력 경로는 표시 배치를 따릅니다. Windows 설정의 배치 그림 자체를 바꾸는 기능은 아닙니다.

Raw Input의 이동량은 Windows 포인터 속도 슬라이더 기준 선형 보정과 사용자 50~400% 배율을 적용합니다. EPP 전체 가속 곡선 재현은 구현하지 않았습니다.

기본 영상 경로는 DXGI Desktop Duplication입니다. WGC의 IsBorderRequired=false를 권한 없이 설정하고 제거됐다고 가정하는 방식을 사용하지 않습니다. 기본 경로에서 WGC 세션을 생성하지 않습니다.
