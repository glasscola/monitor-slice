# v1.2.0 검증

Windows 11 x64, NVIDIA RTX 5060 Ti, 물리 모니터 2개 환경에서 확인했습니다.

- C# 실행 파일 및 C++20 네이티브 DLL 빌드 성공
- 제품명과 DLL 이름 변경 후 실제 분할 통합 검사 통과
- 6가지 배치, 화면 픽셀 출력, 마우스·키보드, 칸 안 최대화, 모니터 간 이동, 종료 복원 확인
- 이전 이름의 앱 소유 설치 기록을 새 설치 경로로 인식하는 경로 확인
- 배포 ZIP은 실행 파일·네이티브 DLL·PDF·README·공식 드라이버 3파일·제3자 라이선스만 포함
- 공식 서명된 드라이버 3파일의 내용은 기존 배포본과 동일
- 한국어 PDF 8페이지의 텍스트·렌더링 확인

설치·반복 설치·복구·장치 제거·신규 설치와 오류 주입 후 롤백은 이전 배포 단계에서 같은 PC로 확인했습니다. 이 PC 외의 신규 환경 전체를 검증한 것은 아닙니다. Windows 관리자 승인과 일부 환경에서 재시작이 필요할 수 있습니다.

개인 아이콘 위치, 시스템 좌표, 드라이버 설치 기록과 런타임 로그는 저장소에 포함하지 않습니다.
